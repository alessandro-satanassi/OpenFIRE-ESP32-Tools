## English

The [Tools portal](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-Tools/?lang=en) collects downloads and utilities for the OpenFIRE ESP32 ecosystem.

For firmware **7.0.0**, the official configuration tool is the [WebApp](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-WebApp/?lang=en), available online over USB serial or offline from the lightgun. If you prefer a program to install, the compatible desktop App, derived from the App of the original OpenFIRE project, is available here in the **OpenFIRE App CUSTOM for ESP32 7.x firmware** section. The other App builds on this page come from the original project and do not work with the 7.x configuration protocol.

For firmware installation use the [Web Flasher](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-WebFlasher/?lang=en). Select Lightgun, Dongle or Pedal and the exact board/memory variant. A clean lightgun installation uses the same firmware image and **erases settings and calibration**.

## Italiano

Il [portale Tools](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-Tools/?lang=it) raccoglie download e utilità per l'ecosistema OpenFIRE ESP32.

Per il firmware **7.0.0**, lo strumento ufficiale di configurazione è la [WebApp](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-WebApp/?lang=it), disponibile online tramite seriale USB oppure offline dalla lightgun. Se preferisci un programma da installare, l'App desktop compatibile, derivata dall'App del progetto OpenFIRE originale, è disponibile qui nella sezione **OpenFIRE App CUSTOM per firmware ESP32 7.x**. Le altre build dell'App presenti in questa pagina provengono dal progetto originale e non funzionano con il protocollo di configurazione della serie 7.x.

Per installare il firmware usa il [Web Flasher](https://alessandro-satanassi.github.io/OpenFIRE-ESP32-WebFlasher/?lang=it). Seleziona Lightgun, Dongle o Pedal e la scheda/variante di memoria esatta. L'installazione pulita della lightgun usa la stessa immagine firmware ed **elimina impostazioni e calibrazioni**.
